# Editorial Change Log — The Sanguinary Proof

**Deep editorial pass**: trimming filler while preserving the contemplative, philosophical voice.

## Edit Categories

| Category | Description |
|----------|-------------|
| **Not X. Not Y. chain** | Halved or reduced multi-negation constructions |
| **Repetitive restatement** | Kept the strongest version of restated ideas |
| **Padding** | Removed phrases that don’t advance plot, character, theme, or atmosphere |
| **Over-explained emotion** | Cut explanation where scene already conveys the feeling |
